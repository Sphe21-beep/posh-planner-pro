# Posh Planner Pro

Build a modern,responsive web application as a computer science diploma student, called Sphe's Beauty Palace AI Productivity Assistant that helps stakeholders automate workplace tasks using AI, the technologies used should be Java, use JPA and HTML for the views, Servlets for control and JPA/JPQL for persistence and data manipulation, classes for the business logic, the application should include a smart email generator, meeting notes summarizer, and an AI task planner ...the dashboard UI should be in a girly kind of way, mind you this is a beauty salon web application so include nails ,hair and lashes images, with a sidebar navigation that leads to the other pages(smart email generator, meeting notes summarizer, AI task planner), every page at the bottom should include a 'contact us' footer, the design style should be similar to a SaaS platform...when the client visits the page, they should be able to set an appointment, cancel their set up appointment, make a payment, log a complaint or a praise.
